### What I learned

I used this project to practice building a simple yet polished component layout from a design asset.

Highlights:
- Creating a centered card layout with flexbox and viewport-based vertical centering
- Matching typography and spacing from the style guide using CSS
- Using an asset-based design reference and building the component with just HTML and CSS

### Continued development

Future improvements I want to focus on:
- moving inline styles into an external stylesheet for better maintainability
- refining responsive behavior for more breakpoints
- adding subtle visual polish while keeping the design minimal and accessible
